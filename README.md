# Station sol (page de test)

Copie de la page opérateur du projet drone de surface, publiée pour essai avec GitHub Pages.

La page n'affiche rien seule : elle se connecte au serveur de la station sol lancé sur le même ordinateur (`python3 serveur.py`, port 8000). Pour un autre serveur : ajouter `?serveur=http://hote:port` à l'adresse.
